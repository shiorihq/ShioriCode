# Fixture policy

Only redacted, synthetic, or explicitly sanitized provider captures belong here. Each fixture records the provider, CLI/SDK or protocol version, capture date, source surface, and redactions in adjacent metadata.

Fixtures are compatibility oracles, not examples of user conversations. Replace prompts, outputs, paths, tokens, account identifiers, repository names, and provider thread IDs while preserving event order, field presence, correlation relationships, and terminal states.

Production correctness must not depend on these files or on access to a developer's home-directory transcripts.
